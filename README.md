# Atoms Lite

一个自然语言驱动的 AI 网页应用生成工作台。输入需求，真实模型生成单文件交互页面，在隔离 iframe 中运行；项目代码与页面业务状态分别保存到数据库。无需注册，支持项目历史和独立 HTML 导出。

## MVP 范围

首版支持单路生成，不实现注册、多路赛马、多文件构建或自定义服务端代码。生成范围是 HTML/CSS/原生 JavaScript 的前端小应用，例如待办看板、计算器与习惯记录器。所有产物通过宿主状态 SDK 保存数据，不依赖 iframe localStorage。

真实生成与示例模式分开标识。示例模式是无额度、网络或模型故障时的交互兜底，不表示 AI 已实时生成；最终演示需要包含真实模型路径。

## 技术结构

React + TypeScript 工作台，Express 单服务，MySQL 持久化及 Drizzle 数据模型。Vite 用于前端构建；后端仅调用模型 API 和保存数据，不执行模型生成代码。`shared/` 保存接口协议、预览 SDK、产物校验和兜底示例；`server/` 保存身份、生成编排与数据库访问；`client/src/` 保存工作台交互。

## 本地运行

Node 22 或更新版本，项目固定 pnpm 10.18.0。安装依赖使用 `corepack pnpm install`，不要擅自升级项目包管理器。复制 `.env.example` 的变量名称，在安全环境中配置真实服务端值；不要提交 `.env`。

托管开发使用 Manus 的开发命令与项目环境注入。普通终端不会自动拥有托管凭据。自行本地启动时应通过受支持的环境加载方式提供配置，再运行 `corepack pnpm dev`；用 `HOST=127.0.0.1` 和选定端口，不要把临时开发端口写进共享配置。

`corepack pnpm check` 执行类型检查，`corepack pnpm test` 执行核心测试，`corepack pnpm build` 构建生产输出，`corepack pnpm start` 启动生产服务。生产监听 `0.0.0.0` 并读取平台提供的 `PORT`。数据库迁移不清表，已保存数据不会因为部署重启而初始化覆盖。

## 业务状态接口

生成页面先调用 `await window.atoms.loadState()` 获取一个 JSON 对象，再调用 `await window.atoms.saveState(nextState)` 保存。预览通信只允许访问当前产物，不向页面传模型 Key、访客凭证或其他项目数据。保存 API 确认成功后才显示已保存；版本冲突和保存失败会明确告知。

## 访问与持久化边界

访客身份保存在宿主浏览器中，数据库只保存凭证哈希。清除站点存储后无法自动找回匿名工作区；首版不提供跨设备账户同步。

生成代码和业务状态保存于持久化数据库，不保存在容器临时目录或内存里。模型任务有界执行，进程重启可能中断正在生成的任务，但已成功保存的项目仍在；用户可以明确重试。

独立导出包含生成代码与当前业务状态，导出适配器使用浏览器本地存储；浏览器禁止存储时会提示未持久保存。导出不连接托管模型，不包含 Key。

## 托管交付条件

采用 Manus 正式发布域名，按用户选择设置按需唤醒，无人访问时可能休眠，下一次访问可能经历冷启动。正式链接独立于开发电脑；部署目标是发布后至少七天可以外部访问。账户服务与余额须保持有效，不删除部署，不改为私有，不以临时 Preview 或隧道代替正式链接。平台故障、服务关闭和余额耗尽不属于本应用可以保证的事项。

真实模型调用使用保守额度限制，示例模式及历史项目可以不调用模型。完整平台计费以账户展示为准，不承诺未经核实的固定一周费用。
